# 全球市场仪表盘 · Global Market Dashboard

一个本地网站，自动每日抓取并展示 **波动率指数**、**中美股指** 与 **中国货币供应 M0/M1/M2**，
带走势对比图、相对波动率图与货币存量图。数据来自各官方接口。

| 代码 | 名称 | 类型 | 历史起点 | 数据条数 |
|---|---|---|---|---|
| **VIX** | 标普500波动率 · S&P 500 Volatility | 波动率 | 1990-01-02 | 9,291 |
| **VXN** | 纳斯达克100波动率 · Nasdaq-100 Volatility | 波动率 | 2009-09-14 | 4,297 |
| **SPX** | 标普500指数 · S&P 500 Index | 美国指数 | 1975-01-02 | 13,052 |
| **NDX** | 纳斯达克100指数 · Nasdaq-100 Index | 美国指数 | 1996-06-06 | 7,814 |
| **SHCOMP** | 上证指数 · SSE Composite | 中国指数 | 1990-12-19 | 8,739 |
| **CSI300** | 沪深300 · CSI 300 | 中国指数 | 2005-01-04 | 5,285 |
| **CHINEXT** | 创业板指 · ChiNext | 中国指数 | 2010-06-01 | 3,971 |
| **M0 / M1 / M2** | 流通中现金 / 狭义货币 / 广义货币 | 货币供应（月度） | **2008-01** | 224 期 |
| **M2 年度延伸** | 世界银行广义货币（现价本币） | 货币供应（年度） | **1977** | 31 年 |

> **为什么 M0/M1 只有 2008 年起？** 央行口径的**月度**货币供应公开数据最早只到 2008-01
> （东方财富接口硬限制，已实测 `count=224`，无更早分页）。更早的月度 M0/M1 公开数据不存在。
> M2 另用**世界银行年度序列**补到 1977 年，见图表说明。

## 快速开始

### 本地运行

```powershell
python app.py          # 启动网站，默认 http://127.0.0.1:8801
```

浏览器打开 <http://127.0.0.1:8801>。Windows 下可直接双击 **`start.bat`**。

### 云端运行（免费）

完整步骤见 **[DEPLOY.md](DEPLOY.md)**。最快路径：

```bash
git init && git add . && git commit -m "init"
git remote add origin https://github.com/<你>/vixvxn.git && git push -u origin main
```

然后 Render → **New → Blueprint** → 选仓库 → Apply（仓库内含 `render.yaml`，自动完成配置）。

### 容器运行

```bash
docker compose up -d --build     # http://localhost:8801
```

云上所需的一切都已内置：`gunicorn` 生产服务器、`PORT`/`HOST`/`DATA_DIR` 环境变量支持、
`/healthz` 健康检查、启动自动播种、外部 cron 入口 `cron_update.py`。

## 图表说明

### 走势对比图

波动率（15~20）、中国指数（3,000~4,300）、美国指数（7,800 / 30,900）量级相差极大，
直接画在一起会互相压平，所以提供两种模式：

| 模式 | 说明 |
|---|---|
| **原始值 / Raw**（默认） | **按市场分 3 条独立坐标轴**：左=波动率 · 右1=美国指数 · 右2=中国指数 |
| **归一化 % / Normalized** | 以所选区间**第一个有效值 = 100**，全部序列同一坐标轴，直接比较涨跌幅 |

> 归一化模式最适合跨市场比较。例如 2019-04 起算，NDX 涨到约 **395**，创业板指约 **170**，
> 沪深300 约 **108**，而上证约 **120**——同期 VIX 只有 **75**（波动率下行）。

其他特性：

- 图例前的**复选框**可单独开关任意序列（7 个标的）
- 时间范围：30天 / 90天 / 1年 / 5年 / 全部
- 横轴取各市场日期的**并集**——A 股与美股交易日历不同，并集可避免丢掉任一市场在对方休市日的行情
- **比值图 VIX ÷ VXN**：观察两个市场恐慌程度的相对变化

### 货币供应图

- 三个卡片显示 M0 / M1 / M2 最新存量、同比、环比
- 图表左轴为**存量**（亿元，**对数刻度**，因为 M0 比 M2 小约 24 倍），右轴为 **M2 同比增速**
- 区间可切 3年 / 5年 / 10年 / 全部

> ⚠️ **2024-01 起 M1 有台阶式跳升**（环比 +64.6%）：这是央行**修订 M1 统计口径**
> （纳入个人活期存款与非银支付机构备付金）所致，**不是真实资金投放**。
> 官方环比字段与跳变一致，可交叉验证。比较该时点前后的 M1 需留意口径差异。

### 货币供应面板（M0 / M1 / M2）

布局对齐参考站点：三张卡片（M2 / M1 / M0）+ 可切换图表。

**三张卡片**分别显示：最新存量（万亿元）、同比、环比、较上月同比变动（pct）、
上月同比，以及折合亿元的原始存量。

**图表三个视图：**

| 视图 | 说明 |
|---|---|
| **存量**（默认） | M1、M2 存量（万亿元）。M0 量级小，默认不显示，可点「仅 M0」单看 |
| **同比** | M0/M1/M2 各自同比增速（%） |
| **剪刀差** | **M1 同比 − M2 同比**（单位 pct）。正值走阔=资金活期化、企业投资意愿偏强；负值=资金定期化、观望情绪浓。柱状图模式下按正负着红/绿色 |

**其他控件：**

- **显示**：M1 + M2（默认）/ 仅 M2 / 仅 M1 / 仅 M0（剪刀差视图下自动隐藏）
- **叠加 A 股指数**：上证指数 / 沪深300 / 创业板指，可多选，走**右轴点位**
- **归一化对比**：所有序列以区间首月为基准换算成相对涨跌 %，同轴比较增速
- **M1 单独轴**：M1 存量约为 M2 的 1/3，同轴时会被压平；开启后 M1 走右轴，两条都看得清
- **柱状图**：剪刀差视图下切换柱状 / 折线
- **区间**：1Y / 3Y / 5Y / 10Y / ALL（最长 224 个月）
- 图例可点击勾选开关任意序列

> **关于横轴**：货币图使用**真实时间轴**（Chart.js time scale + luxon 适配器），
> 1977–2008 年度段与 2008–2026 月度段的宽度严格按真实时间比例，
> 不会因「31 个年度点 vs 224 个月度点」被等距拉伸而失真。
> 若 CDN 不可达会自动回退到类目轴（图形仍显示，仅刻度按等距排布）。
>
> **关于 M2 填充**：仅在「仅 M2」时填充到 0。与 M1 同图时不填充，
> 否则填充会把坐标轴基线拉到 0，M1 被压在底部几乎看不见。

> ⚠️ **2024-01 起 M1 有台阶式跳升**（M1 存量 68.05 → 112.01 万亿元）：这是央行**修订 M1 统计口径**
> （纳入个人活期存款与非银支付机构备付金）所致，**不是真实资金投放**。页面已标注；
> 官方环比字段（+64.6%）与跳变一致，可交叉验证。比较该时点前后的 M1 需留意口径差异。

#### M2 的历史延伸（1977 年起）

在**存量**视图 + **ALL** 区间下，M2 曲线会向前延伸到 1977 年，用**点线**单独绘制并标注「M2 年度（世界银行）」。

| 年份 | 世界银行（亿元） |
|---|---|
| 1977 | 858 |
| 1990 | 14,682 |
| 2000 | 135,960 |
| 2007 | 403,442 |

**两点口径说明（重要）：**

1. **口径不同**：世界银行为**年度值**（年均），央行月度为**月末余额**。
   已实测两者在 **2008–2016 年完全一致（偏差 0.00%）**，2017 年起世界银行低约 **1.7~2.1%**。
2. **不重叠**：年度序列只取 **2007 及更早**，2008 年起交给央行月度数据，避免同一年份两种口径混用。
   衔接点 2007 → 2008-01 为 +3.57%（半年增长，合理）。

> **M0/M1 无法延伸**：世界银行只提供广义货币（M2），没有 M0/M1 的对应指标。
> 若需要更早的 M1，只能依赖二手整理数据，口径风险较高，故未采用。

### 分享特定视图

```
http://127.0.0.1:8801/?days=1825&mode=pct              # 主图：5年 + 归一化
http://127.0.0.1:8801/?mmode=scissors&mrange=ALL       # 货币：剪刀差 + 全部
http://127.0.0.1:8801/?mmode=stock&midx=SHCOMP,CSI300  # 货币：叠加 A 股指数
http://127.0.0.1:8801/?mmode=yoy&mnorm=1               # 货币：同比 + 归一化
```

参数：

| 参数 | 取值 | 说明 |
|---|---|---|
| `days` | `30\|90\|365\|1825\|0` | 主图区间 |
| `mode` | `raw\|pct` | 主图原始值 / 归一化 |
| `mmode` | `stock\|yoy\|scissors` | 货币面板视图 |
| `mrange` | `1Y\|3Y\|5Y\|10Y\|ALL` | 货币面板区间 |
| `mpick` | `m1m2\|m2\|m1\|m0` | 货币显示组合 |
| `midx` | `SHCOMP,CSI300,CHINEXT` | 叠加的 A 股指数 |
| `mnorm` | `0\|1` | 货币归一化对比 |
| `mdual` | `0\|1` | M1 单独走右轴 |
| `mbar` | `0\|1` | 剪刀差柱状图 |
| `hide` | 逗号分隔代码 | 主图隐藏指定标的 |

## 自动更新机制（双保险）

| 方式 | 说明 | 触发时刻 |
|---|---|---|
| **① 网站进程内定时器** | 网站运行期间，后台线程每天自动抓取 | 每天 **06:10**（北京时间）|
| **② Windows 计划任务** | 即使网站没开也独立抓取；下次打开即为最新 | 每天 **06:10**，错过则开机后补跑 |

两者用互斥锁保护，不会重复写入。

```powershell
python setup_task.py                 # 注册（默认 06:10）
python setup_task.py --time 07:30    # 改时间
python setup_task.py --run           # 立即跑一次验证
python setup_task.py --remove        # 删除任务
```

任务名 `VIXVXN_DailyUpdate`；查看 `Get-ScheduledTaskInfo -TaskName VIXVXN_DailyUpdate`

> 计划任务只在**电脑开机**时运行；关机期间不补数据，但历史接口每次返回全量，开机后一次抓取即可补全。

## 数据来源

| 标的 | 历史 | 报价 |
|---|---|---|
| VIX / VXN / SPX | CBOE `cdn.cboe.com/api/global/us_indices/daily_prices/{SYM}_History.csv` | CBOE 延时报价 |
| NDX | 纳斯达克官方 API `api.nasdaq.com/api/quote/NDX/historical` | CBOE 延时报价 |
| 上证 / 沪深300 / 创业板指 | 东方财富 K 线 `push2his.eastmoney.com`；**失败时自动回退新浪财经** | 同左（K 线盘中即实时价）|
| M0 / M1 / M2 | 东方财富数据中心 `RPT_ECONOMY_CURRENCY_SUPPLY` | — |
| M2 年度延伸 | 世界银行 `api.worldbank.org` `FM.LBL.BMNY.CN` | — |

字段对应：`FREE_CASH`=M0、`CURRENCY`=M1、`BASIC_CURRENCY`=M2（单位：亿元，页面换算为万亿元）。

**已知数据源特性：**

- **报价为延时数据**（约 15 分钟），免费接口不提供实时行情。
- **SPX 历史 CSV 只有收盘价**（列名 `DATE,SPX`），故其历史行的开/高/低为空；报价接口的最新值正常。
- **VXN 报价的盘中开高低常返回 0**（CBOE 该字段如此），已统一转成空值，卡片自动回退显示当日历史行情。
- **NDX 早期数据的开/高/低返回 `0.0` 占位**，已在解析时转为空值，避免污染 CSV。
- **东方财富对同一 IP 做偶发性限流**（连接被直接断开，且每次失败的标的都不同，单纯重试不可靠）。
  代码采用 **3 次重试 + 5 秒节流 → 自动回退新浪财经**。
  备用源**只补新、不覆盖历史**：两源在近年完全一致（偏差 0.000%），但新浪的上证指数在
  1990 年代早期与东方财富存在差异（最大约 8%，属早期基期/修订口径不同），故只用于补齐本地缺失的日期。
- 任一源失败都不会覆盖本地已有数据。

## 文件结构

```
vixvxn/
├─ app.py                  # Flask 网站：页面 + API + 进程内定时器
├─ fetch_data.py           # 数据抓取与存储（可独立运行）
├─ setup_task.py           # 注册/删除 Windows 计划任务
├─ start.bat               # 一键启动
├─ requirements.txt
├─ templates/index.html    # 中英双语页面（含全部图表）
├─ static/                 # 静态资源目录（样式内联在页面中）
├─ data/
│  ├─ {SYM}_daily.csv      # 7 个标的的全量日线
│  ├─ {SYM}_latest.json    # 各标的最新报价快照
│  ├─ money_supply.csv     # 月度货币供应 M0/M1/M2

├─ logs/fetch.log          # 抓取日志（UTF-8）
└─ screenshot.png
```

数据是**纯文本 CSV/JSON**，可直接用 Excel 或 pandas 分析。

## 网页 API

| 接口 | 说明 |
|---|---|
| `GET /api/data?days=365` | 日线取最近 365 天（`days=0` 或 `full=1` 取全部）；**货币供应始终返回全量 224 期** |
| `POST /api/update` | 触发后台更新（`?full=1` 为全量） |

返回 JSON：

- `series.{SYM}.{dates,closes,last_close,change,change_percent,rows_total,first_date,...}`
- `cn_monthly.{SYM}.{months,closes,name_zh}` — 中国指数**全量月线**，专供货币面板叠加
  （不能复用 `series`：日线受 `days` 裁剪，而货币面板最长 224 个月）
- `money.{months, m0/m1/m2:{value,yoy}, m*_delta, scissors, latest, source, unit, m2_annual, ...}`
  - `value` 为**万亿元**，`yoy` 为同比 %
  - `latest.{m0,m1,m2}.{value,value_yi,yoy,mom,prev_yoy,yoy_delta}`
  - `scissors` = M1同比 − M2同比
  - `m2_annual.{years,value,source,note}` — 世界银行年度 M2（仅 2007 及更早）
- `specs.{SYM}.{kind,group,name_zh,name_en}` — `group` 为 `vol`/`us`/`cn`
- `meta` — 更新时间、耗时、各标的抓取结果

## 常见问题

**Q：中国指数刷新失败？**
A：东方财富限流。代码已内置节流与重试；失败时保留本地数据，稍后点「立即更新」即可。

**Q：SPX 卡片开/高/低为空？** 见上方「已知数据源特性」。

**Q：M1 在 2024 年初暴涨？** 统计口径修订，非真实投放，页面已标注。

**Q：日志中文乱码？** 控制台乱码是 Windows 代码页问题；`logs/fetch.log` 是 UTF-8。

**Q：数据会重复吗？** 不会。按日期建索引去重合并，写入用「临时文件 + 原子替换」，更新有互斥锁。
反复增量更新后行数稳定为 9291 / 4297 / 13052 / 7814 / 8739 / 5285 / 3971 / 224。
